# Iqra Ashraf — Portfolio

A personal portfolio website built to showcase my projects, skills, and experience as a developer. Designed to give visitors — recruiters, collaborators, and fellow developers — a quick, clean overview of who I am and what I can build.

**Live Link:** [www.iqraashraf.dev](https://www.iqraashraf.dev)

---

## ✨ Features

- **Responsive design** — optimized layout for mobile, tablet, and desktop
- **Smooth navigation** — sticky navbar with active-link highlighting and a mobile drawer menu
- **Sections:** Home, About, Skills, Projects, Contact
- **Animated interactions** — subtle transitions on menu open/close, hover states, and scroll
- **Contact section** with Gmail, GitHub, and LinkedIn links
- **Downloadable resume / CV**

---

## 🛠 Tech Stack

- **[React](https://react.dev/)** — UI library for building component-based interfaces
- **[Vite](https://vitejs.dev/)** — build tool and dev server
- **[Tailwind CSS](https://tailwindcss.com/)** — utility-first CSS framework for styling
- **[Lucide React](https://lucide.dev/) / [React Icons](https://react-icons.github.io/react-icons/)** — icon library

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/ch-iqra-ashraf/portfolio.git
   ```

2. **Navigate into the project directory**

   ```bash
   cd portfolio
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Run the development server**

   ```bash
   npm run dev
   ```

5. **Open the app**

   Visit `http://localhost:5173` in your browser.
